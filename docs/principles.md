# Principles

Important and general considerations that decisions should adhere to.

1. Progress metrics must be earned
   - 'Total reviewed', 'new words', and session score must exist as a reward. The value must have integrity. If it is possible to 'game' a metric (e.g through the peek feature), even inadvertently, the achievement felt from a high number is undermined and the system becomes boring. It must therefore bias towards undercounting rather than overcounting (e.g excluding a valid count over including an invalid count).
   - Particularly considered around the peeking mechanics - peeked (or skipped) words, and words from peeked sentences do not count towards the total reviewed or new word count.

2. Remove all frictions to start
   - No bloat, no decision paralysis, no distracting gamifications - the system is specifically targeted towards people who just want to buckle down and bash out a solid Korean vocab session without inertias.
   - If someone spends 5 minutes on the system, that must be a focused and intentional 5 minutes. Unlike Duolingo, where there are distracting animations and cutscenes which makes it feel slow
   - This includes not inundating the user with decisions - e.g they should not be able to decide how long a session is. It's just 2 minutes.
   - Session time is relevant to this - 2 minutes feels low stakes to start.

3. Immediate feedback
   - Inspired by Csikszentmihalyi's book 'Flow' - immediate feedback is a condition for flow.
   - The summary screen is that feedback, and should be perceived as a reward. It has to arrive immediately, since delayed feedback doesn't hold engagement.

4. Immediate visible progress
   - The user should see a connection between each input and the output. They should see that just doing 2 minutes actually counts for something. For example, this could be doing one sitting and seeing the 'total reviewed' word count climb.
   - This should also be output growth - seeing that their maintained effort leads to growth, rather than a sinkhole. For example, statistics reported relative to aggregated previous sessions, rather than absolute. E.g "60 words in 2 minutes, up from 50 words last week"

5. Defined start and finish to sessions
   - For example, session must have a defined finished time and end with a summary. This closes the psychological loop.
   - Closing the loop is what connects effort to reward - if something is completed and nothing acknowledges it, one's brain gets no clean signal that the work is done, the effort feels like it disappeared, and no habit forms.
